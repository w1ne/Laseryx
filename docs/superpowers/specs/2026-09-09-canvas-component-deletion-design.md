# Canvas Component Deletion

## Goal

Allow components placed on an enclosure source panel to be deleted directly from the canvas using Delete or Backspace, with the same authoritative behavior as deleting through the component editor.

## Interaction

- Selecting any rendered cutout belonging to a source-panel component and pressing Delete or Backspace removes the complete component instance.
- A multi-path component is atomic: selecting a button opening, display opening, acoustic opening, or mounting hole removes the component and all of its rendered paths together.
- If selected paths belong to multiple source-panel components, all identified components are removed once.
- The existing component-editor Delete button remains available.

## Data integrity

Rendered `components-box:*` objects remain derived and cannot be deleted directly. The deletion service parses only source-panel cutout IDs generated by the enclosure renderer, resolves their component IDs against `document.enclosureWorkspace.sourcePanel.components`, and updates that authoritative collection.

Deleting a component clears the current object selection, removes any generated enclosure result, and removes its sheet layout because both are stale. Other workspace values and unrelated document geometry remain intact. Generated faces, joints, panel outlines, anchors, fit coupons, and sheet boundaries stay protected.

Mixed selections containing both source components and unrelated objects are rejected rather than partially deleted across two ownership models. Component deletion is supported in the editable source-panel state; arbitrary paths on an already-generated face do not acquire inferred component ownership.

## Four-button mounting pattern

The `TACTS-12MOD-4CH` measured preset gains four corner mounting holes in addition to its four button openings:

- Each mounting hole is 3.5 mm in diameter.
- Hole centres are 2 mm from the 86.5 × 20 mm board edges, leaving approximately 0.25 mm between each hole edge and board edge.
- Component-local centres are `(-41.25, -8)`, `(41.25, -8)`, `(-41.25, 8)`, and `(41.25, 8)` millimetres.
- The values are user-measured approximations and remain part of the editable component mechanics.
- Dragging or deleting any of the eight rendered openings acts on the complete four-button component.

## Verification

- A service regression test selects one mounting-hole path and verifies the whole component disappears.
- A multi-selection regression test verifies multiple component IDs are deduplicated and removed together.
- Tests verify enclosure results and sheet layout are invalidated while unrelated document objects remain.
- Catalog and expansion tests verify the four Ø3.5 mm button-board mounting holes at the approved coordinates.
- Existing protected generated-geometry deletion tests continue to pass.
- Run the full test, lint, and production build gates before integration and deployment.
